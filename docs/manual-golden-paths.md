## 既知バグ・対症療法の一覧（R0 棚卸し）

リファクタ中に「直したくなる」もの。**R1 では移植し、R2 以降で構造的に直す**:

| 症状 | 現在の対症療法 | 恒久対応 |
|---|---|---|
| 外クリックで copilot が死ぬ | `handleResignActive` に `isCopilotActive` ガード | PanelSpec.isModal（R2） |
| 合成クリック後パネルが復帰しない | 1セッション1アクションに制限＋`orderFrontRegardless` | activate 一元化で再挑戦（R2） |
| 管理ウィンドウが前面に引っ張られる | なし（未修正） | PanelSpec.activates（R2） |
| transform への暗黙突入が分かりにくい | モードバッジ・文言で可視化 | 遷移表で明示（R1）＋UI検討 |
| `isCapturingScreenshot` が2箇所 | 手動同期 | AppMode.capturing に一本化（R1） |
| 起動直後ジェスチャ不発 | AX許可監視でモニタ再登録（修正済み） | — （回帰確認のみ） |
