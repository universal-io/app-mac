## Compose

- [ ] 右Shift 2回で入力パネルが開き、下書きへフォーカスする。
- [ ] Enterで下書きが対象アプリへ送信される。
- [ ] レビュー完了後も下書きへフォーカスが残り、Enterは下書きを送信する。
- [ ] 明示的にレビュー欄へ切り替えた時だけレビュー案を送信できる。
- [ ] 入力履歴は初期状態で閉じており、開いて選ぶと送信せず下書きへ復元する。
- [ ] レビュー前はレビュー枠を表示しない。
- [ ] Gatewayエラーはパネル全体のエラーとして表示する。
- [ ] リッチテキスト、画像、ファイル、複数itemをclipboardへ入れてから送信すると、対象欄へ本文が
  1回貼り付けられ、clipboardには送信本文だけが残り、時間差で過去内容へ戻らない。
- [ ] Compose送信直後に別アプリで⌘Cすると、その新しい内容が後から上書きされない。
- [ ] Accessibilityを拒否した状態で送信すると、本文がclipboardへ残り、手動⌘Vと設定導線が
  明示される。手動⌘Vで同じ本文を貼り付けられる。

## 長時間稼働（R11 D7）

2026-08-03、約38時間連続稼働したプロセスでVisionが無音停止した。24分前の同じ画面では完走
しており、起動直後だけを確認するチェックリストでは原理的に検出できない。**リリース前に必ず
実施する。** ここを通さずに公開すると、公開後に「再起動してください」と案内することになる。

**1回目の試行（2026-08-03 21:53:01 → 2026-08-04 22:15:12、24時間22分）は未達で終わった。**
稼働時間は24時間を超えたが、**最後の操作は14:53（稼働17時間時点）で、24時間到達後の21:53〜22:15は
無操作のまま正常終了した**。このチェックリストが求めているのは稼働時間そのものではなく
「24時間を超えたプロセスで各操作が通ること」なので、**時間だけ経過しても通過にはならない**。
次回は24時間到達の直後に下の各項目を実施する。プロセスは`ps -o etime -p <pid>`で確認できる。

**2回目の試行（2026-08-09 01:43:50 → 2026-08-10、`0.2.2` build `7`、32時間50分）は9項目中7項目が
通り、項目6で欠陥を見つけて未達で終わった。** 通った7項目の内容は次のとおりで、いずれもクライアント
のunified logとSupabase `bs_usage_events` の双方で裏を取った。

- Compose：`suggest`／`review`／`composeDeploy` がいずれも成功（`review` はこの試行まで
  2026-07-24以降1度も実行されていなかった）。
- Vision・Copilot：`vision.request` 6件に対し `vision.turn` 6件。取りこぼしゼロ。
- 音声入力：`transcribe` 成功（8秒、439ms）。
- 異常イベント（`failed`／`deadlineExceeded`／`cancelledUnexplained`／`screenshotUnreadable`）は
  32時間の全期間で0件。
- オフライン：Vision が51msで明示的に失敗し、Wi-Fi復帰後に正常応答へ戻った。
- 再起動メニュー：0.85秒で新プロセスへ移り、ログイン状態と未送信下書きが残存した。
- 動作記録の privacy：全123行に本文・回答・ウインドウタイトル・ホスト名なし。

**項目6が落ちた。32時間50分稼働したプロセスが `uptime=0h0m` を出力した。** 稼働時間に関係なく常に
