# Jev実験の記録（2026-09-20）

最終更新: 2026-10-08 ／ ステータス: 終了（導入は見送り）

AXの候補一覧だけを判断モデルに渡して「次に押すもの」を選ばせた実験。導入は見送ったが、
**どこで試すべきかは確定した**ので、次に試すときにやり直さずに済むよう、結論と部品の在処を残す。

## 何を試したか

Jev は TypeSafe の判断モデル（`typesafe/jev-1.13`）。選択肢と基準を渡すと1つを選び、
全選択肢の確率と確信度を返す。

仮説: VLM は撮影と推論の分だけ常に一歩遅れる。AXの候補（label / role / parent / states。
画像・座標なし）と目的だけなら、安く速く次の一手を選べるのではないか。

試した順:

1. 合成入力で疎通（OpenRouter Decisions API）
2. GA4 の実画面のAXを Mac の Debug 版で取り、CLI で1手ずつ判定
3. GA4 で連続判定（`--explore`: 状況〔続行／完了／待機／情報不足〕と次の一手を別々に問う。
   ループ防止つき）。操作は Chrome DevTools MCP 経由でエージェントが行った
4. Google カレンダーで予定作成を通しで（v1: Jev は対象だけ選ぶ／v2: 操作種別と値まで選ぶ／
   v3: 中継のLLMを外したプログラムだけのループ）

TypeSafe の公式APIはウェイティングリストで使えず、OpenRouter 経由
（`POST https://openrouter.ai/api/alpha/decisions`）で呼んだ。Gateway のルート
`/api/ai/jev-candidates` も作ったが TypeSafe 直結のままで配備していない。
**Mac → Gateway → Jev の経路は一度も通っていない。**

## 結論

- **1手の判断は速く安い。** 1回 0.5〜0.7秒。全実験の費用が $0.025。
- **目的を保って進むことと、止めどきの判断が弱い。** 1手ずつは選べても、連続すると崩れた:
  - 指標を取り違える（GA4 で「アクティブユーザー」を求めて「総ユーザー数」の表で止まる）
  - 説明ボタンと操作ボタンを混同する
  - 同じ操作を繰り返す（しかも確率 0.94〜1.00 で）
  - 状況は「続行」なのに、次の一手は「完了」と答える
- **お膳立てが重い。** 履歴・ループ防止・到達判定・操作種別と値の候補をタスクごとに用意しないと
  何もできない。用意すると、判断以外（操作・描画・AX取得・中継するLLM）の時間が支配的になる。
  カレンダーの通し（v3）は全体 37.5秒で、Jev の判断はそのうち約5秒。
- **確信度は校正されていない。** 正しい手は 0.2〜0.5 の僅差が多く、誤ったループで 0.94〜1.00 が出た。

オーナーの総括:「Jev を使えるようにして、APIを読めるようにした。いくつか試した。
導入は未定だが、試しどころは確定した」

## 試しどころ（次にやるなら）

Jev 単体にナビゲーションさせるのではなく、**自動で進める案内（autopilot）の本体を先に作り、
その中で Jev あり／なしを比べる。** 比べ方は A＝VLMだけ、B＝ルール＋VLM、C＝条件つきで
Jev を挟む。**C が B に勝たなければ棄却する。**

挟みどころの候補:

- 予定した進行どおりに画面が変わったかの照合（予定どおり／変化なし／外れた／材料不足／上位へ）
- ユーザーの操作を受けて「いま LLM / VLM を起こすべきか」の判定
- VLM に渡す候補の絞り込み、VLM との投機的な並走

## AXについて分かったこと（Jevに限らず使える）

AXから「いま見えている要素」を作る仕事（たとえば声の相棒の先読み。app-web の
`docs/voice-companion-native.md` R9）にそのまま効く。

- `ax:N` の id は取得ごとに振り直される。画面をまたいで同じ要素を指すには
  label＋role＋parent＋states（semantic key）で照合する
- 見た目の部品1つが複数のAXノードになる（button と子の popupbutton。同じ semantic key が3件）。
  「どれを押すか」の案内が曖昧になる
- GA4 のフィルタパネルには menu / menuitem が無い
- GA4 の表の値はAXで取れる。254件の上限には届かなかった（最大 149件）
- AX全文（verbose、約10万字）は Jev の入力上限（32K）を超えて HTTP 400。
  compact にすると（約1.4万字、16.7k tokens）通った
