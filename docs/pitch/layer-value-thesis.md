# レイヤーの価値の定義 — ピッチの手前の第一原理思考

作成: 2026-07-05
目的: 「この透明なレイヤーの価値を最大化するなら、どんな振る舞い・形か」をエレベーターピッチの手前で定義する。v1 ピッチ（`investor-pitch-v1.md`）への批判（OS吸収リスク／事業ペイン不明／PMF未定義）への回答を兼ねる。

---

## 1. 「OSに吸収される」への正面回答

半分正しい。汎用リライト（Apple Writing Tools 等）と汎用の画面説明（Copilot Vision / Gemini 等）は吸収される。吸収され**ない**ものは構造的に4つ:

1. **人に付いて回るコンテクスト**: OSベンダーはロックインで儲けるため、端末・エコシステムを横断する「あなた」を作る動機がない。会社のWindows、家のMac、ポケットのAndroidで同じ「あなた」を知っているのは中立レイヤーだけ。
2. **両側性（N者間プロトコル）**: OS機能はシングルユーザー。送信側ガードレール×受信側デコーダが両側で動いて初めて「事故ゼロ」になる。ネットワークはOSの機能からは生まれない。
3. **説明責任のあるドメインハーネス**: 汎用リライトと「わが社のトーン・規程・業務で、監査可能に」は別物。これは事業でありOS機能ではない。
4. **「いつ話しかけるか」モデル**: 透明な膜の価値は介入の精度。誤介入1回で信頼が死ぬ。この判断器は蓄積されたコンテクスト資産の上にしか作れない。

守るべき本体は「膜」そのものではなく、膜の下の**本人所有のコンテクスト資産**・**両側性**・**介入精度**。

## 2. 4つのレンズでの定義

- **Musk（第一原理）**: あらゆるワークフローで最も帯域が狭くエラー率が高いリンクは人間（タイピングは実効 ~10 bits/s）。全システムの速度はボトルネックリンクで決まる。I//O = **人間リンクの誤り訂正層**。Neuralinkが手術で解こうとする問題をソフトウェアの義肢で解く。単一の物理的メトリクス（誤介入率、防いだエラー数/日）で経営する。
- **Gates（プラットフォーム）**: 機能ではなくプラットフォームたれ。L2/L3 のコンテクストカード＝**意図の時代のファイルフォーマット**。「私が誰で、誰にどう話すか」のスキーマを標準化した者が次のWindowsになる。ハーネス開発者＝ISV。安く広く座席を取り、エコシステムで回収。
- **Altman（能力曲線）**: モデルは堀にならない。**今日のモデルが「ほぼ」できることを作れば、世代交代のたびに製品が勝手に10倍良くなる**。堀は (1) 同意ベースで蓄積された個人メモリ (2) 毎日の習慣＝配布。まず「これが消えたら絶望する100人」を作る——それはケア・ニューロダイバーシティの現場にいる。
- **Dorsey（プロトコルと尊厳）**: コンテクストは端末に留め、出るのは蒸留された抜粋のみ。カードはオープンな持ち運び可能フォーマットにし、ユーザーの資産にする。機能を削ぎ、ジェスチャは一つ。Squareが銀行に無視された商店から始めたように、**尊厳が懸かっている場所**（無視されてきた働き手）から始める。

## 3. 私の定義: エージェント時代の「人間の座席」

エージェントが実行を担う世界で、人間に残る仕事は**判断と承認**に圧縮される。次の10年で最も価値あるUIの座席は「人間が確認し、承認する場所」。I//O は最初から「自動送信しない・最終判断は人間」を原則にしている。つまり:

> **Universal I/O は、エージェント時代の人間の座席（approval seat）を作る会社。**

OSとラボが「どこまで自動でやれるか」を競うほど、「人間の主権をどう残すか」の中立レイヤーの価値が上がる——カウンターポジション。ガードレール／コパイロット／カーナビは、この座席の3つのモードにすぎない。

## 4. 最大価値の振る舞い（膜の設計原則）

1. **介入の希少性**: 1日に数回、本当に必要なときだけ。「よく黙っている」ことが品質。競争軸は機能数ではなく誤介入率。
2. **対話に開ける**: 「なぜ修正が必要か」を聞ける。無視して意図どおりに送れる。この修正差分こそ最良の学習データ。
3. **人に付いて回る**: デバイスでも雇用主でもなく本人の資産。編集可能・削除可能・持ち運び可能。
4. **両側で動く**: チームに配ると複利。送信側の矯正と受信側の防御が噛み合った組織は事故率が構造的に下がる。
5. **ハーネスで職業的になる**: 経理には経理の、福祉には福祉の判断基準。汎用の上に載る「専門性」が課金対象。

## 5. PMFシナリオ（現時点の賭け）

「B2Bはミッションからの逃げ」批判への答え: **当事者市場そのものがB2Bである**。

- 法定雇用率は 2026年7月に 2.7% へ引き上げ（まさに今月）。未達企業には納付金。精神・発達障害者の職場定着率は低く（1年で約半分という調査）、定着支援・雇用管理には助成金が出る。
- つまり買い手（特例子会社・就労移行支援事業所・人事）には**予算と、行政指標と一致する測定可能なKPI（定着率）**が既にある。LITALICOが上場企業として存在すること自体が「この市場は払う」証拠。
- ファウンダーは当事者。売る相手は「ファウンダーが助けたい人を雇う組織」。ミッションとGTMが一致する。

段階:
1. **楔**: 定着支援ツールとして特例子会社・就労支援でパイロット。KPI＝定着率・独り立ちまでの時間・エスカレーション率
2. **反転**: 同じ膜を「周囲の全員」に配る（両側性）。ここで福祉ツールから全社コミュニケーションSaaSに化ける
3. **横展開**: 職種・業種ハーネスのテンプレート化（限界費用ゼロで N 社目に効く）
4. **個人**: 人に付いて回るコンテクスト資産として端末・雇用主を越える

「なぜ出資が必要で、返るのか」: 助成金でCACが構造的に低い楔／KPIが行政指標と一致し更新が固い／両側配布でNRRが伸びる／ハーネスはテンプレ化でスケール／最後はコンテクスト資産のスイッチングコスト。

## 6. 正直な留保

- 出力側（画面カーナビ）はOS・ラボの主戦場。そこ単体では勝負しない。入力側＋関係性メモリが先で、出力側はアクセシビリティの正当性（権限の堀）が効く現場から。
- 「透明な膜」の体験は誰もまだ精度で成立させていない。最初の6ヶ月の本当の勝負は誤介入率。
- 本ドキュメントの統計値（法定雇用率・定着率・納付金額）はピッチ資料化の前に一次ソースで裏取りすること。
